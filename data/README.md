# Data provenance & licenses

## Evaluation set — FLORES+ (FLORES-200)
- Source: `openlanguagedata/flores_plus` on Hugging Face (Open Language Data Initiative).
- License: **CC BY-SA 4.0**. Attribution + ShareAlike required.
- **Gated:** requires HF login and accepting the dataset terms before download.
- Configs used (language codes): `eng_Latn` (en), `hin_Deva` (hi), `guj_Gujr` (gu).
- Split: `devtest` (1012 parallel sentences); `dev` (997) available.
- Parallel by construction (same meaning across languages), aligned on the `id` field.
- `data/eval/{en,hi,gu}.jsonl` are GENERATED by `scripts/build_eval_set.py` and gitignored.
